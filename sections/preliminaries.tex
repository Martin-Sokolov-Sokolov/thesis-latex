\section{Preliminaries}

\noindent In this section, we provide the reader with the necessary information in order to follow the paper. We start 
with a reminder of Graph Theory. After that, we move to more advanced definitions in the field of 
Combinatorial Optimization. Finally, we get on topic by introducing perturbation resilience and certified 
algorithms from the field of Beyond the Worst-Case Analysis of Algorithms.

\subsection{Graph Theory}

\noindent In this section, the authors refer to Bondy and Murty \cite{bondy1976graph}.
A \textit{graph} $G$ is an ordered pair denoted as $(V(G), E(G))$.
The set $V(G)$ is called a set of \textit{vertices} and the set $E(G)$ is a set of \textit{edges}.
The incidence function $\psi_G$ associates each edge with an unordered pair of 
(not necessarily unique) vertices. The ordered pair and the incidence function define the graph $G$.
We are going to use $n$ as the cardinality 
of the set $V$ and $m$ for the set of edges $E$. With each edge $e$ of G, let there be associated 
a real number $w(e)$, called its \textit{weight}. Then G, together with the weighting function 
$w : E \to \mathbb{R}$, is called a \textit{weighted graph}, and denoted $(G, w)$.

\noindent A graph can be \textit{embedded in the plane} or is \textit{planar} if it can be drawn on the 
plane in a way that edges intersect each other only at their ends. Such a drawing is called a 
\textit{planar embedding} of the graph. A graph $G$ is called \textit{outerplanar} if it has a 
planar embedding $\widetilde{G}$ in which all the vertices lie on the boundary of the outer face. 
This is also called a \textit{1-outerplanar graph}. Two forbidden minors of that class are the 
$K_4$ and $K_{2, 3}$ graphs. In the next subsection, we familiarize the reader with Baker's approach 
\cite{Baker}. Here, we define a \textit{$\ell$-outerplanar} to be a graph that has a planar embedding in which 
the vertices belong to at most $\ell$ concentric layers. Every planar graph is \textit{$\ell$-outerplanar} for 
some $\ell$. Given a graph $G$, we look for the \textit{$\ell$-outerplanar} embedding of $G$ for which $\ell$ is minimal.

\subsection{Combinatorial Optimization}

\noindent In this section, we refer to the book on Combinatorial Optimization by Korte and Vygen \cite{Korte2007CombinatorialOT} and 
Williamson and Shmoys \cite{williamson2011design}. Some definitions can be traced to the end of the book by Cygan et al. \cite{cygan2015parameterized}. 

\subsubsection{NP-Complete Problems: Definitions and Variants}

We are going to be looking at a couple of problems, namely the \textsc{Feedback Vertex Set}, the \textsc{Cycle Packing} problem and
the \textsc{Travelling Salesman Problem}. 
All of those problems belong to the class of \textbf{NP-complete} problems. 
The decision variant of the \textsc{FVS} problem can be defined as:

\refstepcounter{definition} % Increment counter after the definition content
\begin{mydefinition}[Feedback Vertex Set (\textbf{FVS})]{Definition}

    \label{FVS}
    \textbf{Input:}
    A graph $G$ and an integer $\ell$.

    \textbf{Question:}
    Does there exist a set $X$ of at most $\ell$ vertices of $G$ such that $G - X$ is a forest?
    
\end{mydefinition}

\noindent The weighted optimization version of the problem can be defined as:

\refstepcounter{definition} % Increment counter after the definition content
\begin{mydefinition}[ Minimum Weight Feedback Vertex Set (\textbf{MWFVS})]{Definition}
    \label{MWFVS}

    \textbf{Instance:}
    \begin{itemize}[noitemsep, topsep=0pt]
        \item An undirected weighted graph $(G, w)$, where $G = (V, E)$ and $w: V \to \mathbb{R}$.
    \end{itemize}
    \textbf{Task:}
    Find a vertex set $X \subseteq V$ such that:
    \begin{itemize}[noitemsep, topsep=0pt]
        \item \( G \setminus X \) is acyclic (i.e., a forest)
        \item The sum of the weights of the vertices in $X$ is minimized.
    \end{itemize}

\end{mydefinition}

\noindent In some sense, the \textsc{Cycle Packing} problem is dual to \textsc{FVS}. We use the definition from the blue book of Cygan et al. \cite{cygan2015parameterized}.

\refstepcounter{definition} % Increment counter after the definition content
\begin{mydefinition}[Cycle Packing]{Definition}
    \label{def:CYCP}

    \textbf{Input:}
    A graph $G$ and an integer $\ell$.

    \textbf{Question:}
    Does there exist in $G$ a family of $\ell$ pairwise vertex-disjoint cycles?

\end{mydefinition}

\noindent The other problem we inspect is an edge-optimization problem, namely the \textsc{Travelling Salesman Problem} (TSP).

\refstepcounter{definition} % Increment counter after the definition content
\begin{mydefinition}[Travelling Salesman Problem (\textbf{TSP})]{Definition}
    \label{TSP}

    \textbf{Instance:}
    \begin{itemize}[noitemsep, topsep=0pt]
        \item A set of cities $C = \{c_1, c_2, \ldots, c_n\}$.
        \item A distance function $w: C \cdot C \to \mathbb{R}$ that gives the distance between each pair of cities.
    \end{itemize}
    \textbf{Task:}
    Find a permutation $\pi$ of the cities such that:
    \begin{itemize}[noitemsep, topsep=0pt]
        \item The total distance travelled is minimized, i.e., minimize 
        \begin{align*}
            \sum\limits_{i=1}^{n-1} w(c_{\pi(i)}, c_{\pi(i+1)}) + w(c_{\pi(n)}, c_{\pi(1)}).
        \end{align*}
    \end{itemize}

\end{mydefinition}

\noindent We define the problems \textsc{FVS-BCL}, \textsc{MWFVS-BCL} and \textsc{Cycle Packing-BCL} to be the problems that cover
and pack cycles of bounded length. The \textsc{'BCL'} stands for bounded cycle length. We give the following definitions:

\refstepcounter{definition} % Increment counter after the definition content
\begin{mydefinition}[FVS-BCL]{Definition}
    \label{FVS-BCL}

    \textbf{Input:}
    A graph $G$, integer $\ell$ and an integer $r$.

    \textbf{Question:}
    Does there exist a set $X$ of at most $\ell$ vertices such that every cycle of length at most $r$ contains a vertex in $X$?

\end{mydefinition}

The following is the weighted version of the problem; we define it as an optimization task.

\refstepcounter{definition} % Increment counter after the definition content
\begin{mydefinition}[MWFVS-BCL]{Definition}
    \label{MWFVS-BCL}

    \textbf{Instance:}
    \begin{itemize}[noitemsep, topsep=0pt]
        \item An undirected weighted graph $(G, w)$, where $G = (V, E)$ and $w: V \to \mathbb{R}$ and an integer $r$.
    \end{itemize}
    \textbf{Task:}
    Find a vertex set $X \subseteq V$ such that:
    \begin{itemize}[noitemsep, topsep=0pt]
        \item Every cycle in \( G \setminus X \) of length $\leq r$ has a vertex in $X$.
        \item The sum of the weights of the vertices in $X$ is minimized.
    \end{itemize}

\end{mydefinition}

Finally, we define the maximization problem with an additional constraint:

\refstepcounter{definition}
\begin{mydefinition}[Cycle Packing-BCL]{Definition}
    \label{CYCP-BCL}

    \textbf{Input:}
    A graph $G$, an integer $\ell$ and an integer $r$.

    \textbf{Question:}
    Does there exist in $G$ a family of $\ell$ pairwise vertex-disjoint cycles with each of them having length $\leq r$?

\end{mydefinition}

\subsubsection{Approximation Algorithms and Complexity Classes}

\noindent As we mentioned, all the problems are \textbf{NP-complete}, so we turn to \textit{approximation algorithms} 
in order to cope with the hardness of the problems. Let $\Pi$ be an optimization problem with nonnegative weights 
and $k \geq 1$.
A \textit{k-factor approximation algorithm} for $\Pi$ is a polynomial-time algorithm $A$ for $\Pi$, 
such that \[\frac{1}{k} \cdot OPT(I) \leq A(I) \leq k \cdot OPT(I)\] for all instances $I$ of $\Pi$.
The first inequality shown is true for maximization problems, while the second one holds for minimization problems.
We say $A$ has a performance ratio of \textit{k}. If a problem falls into that category, we say that it is \textbf{APX-complete}. 

\noindent In the last paragraph, we mentioned the class of problems \textbf{APX} regarding approximation algorithms. Now we turn 
to another class of approximation algorithms. \textbf{PTAS} is a class of algorithms that work in polynomial time and get close to an optimal 
solution with a trade-off. 

\refstepcounter{definition} % Increment counter after the definition content
\begin{mydefinition}[ Polynomial-Time Approximation Scheme (PTAS)]{Definition}
    \label{PTAS}
    
    A polynomial-time approximation scheme (\textbf{PTAS}) is a family of algorithms ${A_{\epsilon}}$ where there is an algorithm for each $\epsilon > 0$, 
    such that $A_{\epsilon}$ is a $(1 + \epsilon)$-approximation algorithm (for minimization problems). The running time of the algorithm $A_{\epsilon}$ 
    is polynomial, but can depend arbitrarily on $1/\epsilon$. This dependence could be exponential or even worse.
    Thus an algorithm running in time $O(n^{1/\epsilon})$ counts as a PTAS.

\end{mydefinition}

\noindent Every problem with a PTAS is also in APX. The relation between these two classes is similar to the one between 
\textbf{P} and \textbf{NP}. For more on the topic, such as APX-completeness, L-reductions and the PCP-theorem, 
we refer to Korte and Vygen \cite{Korte2007CombinatorialOT}.

\noindent An important distinction in the complexity zoo is made in Cesati and
Trevisan \cite{cesati1997efficiency}. To the best of the knowledge of the author, this is the paper 
that describes what an efficient PTAS is.

\refstepcounter{definition} % Increment counter after the definition content
\begin{mydefinition}[Efficient Polynomial-Time Approximation Scheme (EPTAS)]{Definition}
    \label{def:EPTAS}
    
    An efficient PTAS yields a $(1 + \epsilon)$ approximation scheme and has a running time 
    of $f(\epsilon) \cdot n^{c}$ where $f$ is an arbitrary function and $c$ is a constant. 

\end{mydefinition}

\subsubsection{Baker's approach}

\noindent In this subsection, we are going to describe the Shifting technique. It is described in Baker's seminal paper \cite{Baker}.
What she describes is a general algorithm that partitions the graph into a disjoint union of levels of vertices. By analysing slices of these 
levels and, more specifically, the overlap between these slices, one obtains an approximation ratio for the solution to the optimization 
problem. The slices make up several levels that are specifically chosen for a problem and it should hold that an exact solution 
can be found on one slice. It must also hold that this solution can be found in optimal time. 

\noindent There is also another way to view this approach. Instead of analysing the overlap between slices, one could partition the graph 
by removing said overlap. This way we get a disjoint union which does not sum up to the total solution, but we can argue that we did not stray 
away so much from the optimum solution. This approach works for hereditary maximization problems like \textsc{Independent Set}, \textsc{Max-Cut}, 
\textsc{Maximum P-Matching}, etc. 

\noindent We are going to give two examples. The first is the general shifting technique and the example problem for it will be \textsc{Vertex Cover}. 
Then we will explore the second perspective and take the \textsc{Independent Set} problem as an example. It is important to note that the general technique is 
much more powerful than partitioning by removal of vertices. With \textsc{Vertex Cover}, we can still use the second approach 
and get a PTAS, but the same does not hold for the \textsc{Dominating Set} problem. However, using the general shifting technique, we can obtain a 
PTAS for \textsc{Dominating Set} in planar graphs. This was done by Marzban and Gu \cite{dominatingsetptas}. They designed a PTAS with an 
approximation ratio of $(1 + 2/\ell)$ in $O(2^\ell \cdot n)$ time. The two in the approximation ratio appears because of the overlap needed 
for \textsc{Dominating Set} between slices, which is two levels of overlap.

\noindent What follows is a brief explanation of Baker's shifting technique with \textsc{Vertex Cover} as an example.

\begin{algorithm}[H]
    \caption{Baker's shifting technique}
    \label{alg:baker}
    \begin{algorithmic}[1]
    \REQUIRE Planar graph $G = (V, E)$, parameter $\ell$
    \ENSURE $(1 + \epsilon)$-approximation for \textsc{Vertex Cover}
    \STATE Perform \textsc{BFS} from some arbitrary vertex $r$
    \STATE $S \leftarrow \emptyset$

    $i$: \textit{shift}; $j$: \textit{slice}

    \FOR{each $i = 0$ to $\ell - 1$}
        \STATE Let $G_{i, j}$ be the subgraph induced on vertices at levels $j \cdot \ell + i$ through $(j+1) \cdot \ell + i$ for $0 \leq i < \ell$. \label{line:4}
        \STATE $\forall j \text{ compute }  S_{i, j}$, the min. \textsc{VC} of $G_{i, j}$.
        \STATE $\forall j \text{ let } S_i = \bigcup_{j} S_{i, j}$
        \STATE $S \leftarrow S \cup S_i$
    \ENDFOR
    \RETURN $S_{i*}$ from $S$ with minimum cardinality
    \end{algorithmic}
\end{algorithm}

\noindent Analysis of the algorithm:

\noindent Let \( V_i \) be the set of vertices at levels \( i \mod \ell \):
\[ V_i = \{ v \in V \mid \text{level}(v) \equiv i \mod \ell \} \]

\noindent Let $OPT_i$ denote $OPT \cap V_i$. We notice that $OPT_i$ are disjoint and $OPT = \bigcup_{i} OPT_i$. 
Therefore, we can make the following argument: 

\begin{enumerate}
    \item $\exists q: |OPT_q| \leq \frac{1}{\ell} \cdot OPT = \epsilon |OPT|$
    \item $S_q \leq \sum\limits_{j} S_{q, j}$, for some shift $q$ we have this inequality because in step 5. of the algorithm 
    we define the set to be a union over all slices and some vertices may appear twice in the boundary layers. 
    \item $\sum\limits_{j} S_{qj} \leq \sum\limits_{j} |OPT \cap V(G_{q, j})|$, we know that $S_{q, j}$ is a min. \textsc{VC} for $G_{q, j}$, while the 
    optimal solution may choose different vertices, especially on the boundary for the global optimality of the solution.
    \item $\sum\limits_{j} |OPT \cap V(G_{q, j})| \leq |OPT| + |OPT_q|$, if we consider the graphs $\{G_{q, j}\}$, then we can argue that 
    each vertex appears once, except those at levels $q \mod \ell$, which appear twice. 
\end{enumerate}

\noindent From the first, second and fourth step we can conclude that: \[S_q \leq |OPT| + |OPT_q| \leq (1 + \epsilon) \cdot |OPT|\]

\noindent Now we take a look at the second approach we described.

\begin{algorithm}[H]
    \caption{Baker's technique with removal}
    \label{alg:bakeremoval}
    \begin{algorithmic}[1]
    \REQUIRE Planar graph $G = (V, E)$, parameter $\ell$
    \ENSURE $(1 - \epsilon)$-approximation for \textsc{MIS}
    \STATE $S \leftarrow \emptyset$
    \STATE Perform \textsc{BFS} from some arbitrary vertex $r$
    \STATE $\ell \leftarrow 1/\epsilon$
    \STATE Label each vertex according to its layer $i \mod \ell$: ${V_1, V_2, \dots V_{\ell - 1}}$
    \FOR{each $i = 0$ to $\ell - 1$}
        \STATE Let $G_{i} \leftarrow G \backslash V_i$
        \STATE Let $G_1, G_2, \dots G_j$ be the connected components of $G_i$
        \STATE $\forall j$ compute the MIS $S_{i, j}$ of $G_{i, j}$
        \STATE $S_i \leftarrow \bigcup_{j} S_{i, j}$
        \STATE $S \leftarrow S \cup S_i$
    \ENDFOR
    \RETURN $S_{i*}$ from $S$ with minimum cardinality
    \end{algorithmic}
\end{algorithm}

\noindent Consequence of the algorithm:

\begin{enumerate}
    \item for $\ell = 1/\epsilon$ compute partition $P_1, \dots , P_k$.
    \item for some $q$ ($1 \leq q \leq \ell)$, $|OPT \cap P_q| \leq \frac{1}{\ell} \cdot |OPT| = \epsilon \cdot |OPT|$ because 
    of the pigeonhole principle
    \item hence, $|OPT \cap (G - P_q)| \geq (1 - 1 / \ell) \cdot |OPT| = (1 - \epsilon) \cdot |OPT|$
    \item return $max_i{|\text{\textsc{MIS}}(G - P_i)|}$
\end{enumerate}

\noindent We skip much of the analysis that we did for the shifting technique, however, we argue that for this particular problem for some $P_q$,
a small fraction of the solution resides within that partition. Therefore, we can forget about that part and the rest of the solution will still 
be an independent set of bounded size.

\noindent The first approach is more general and powerful for constructing algorithms, but it doesn't apply well to the \textsc{Dominating Set} problem.
The key issue is that the removal technique relies on intersecting an optimal solution with a subgraph, expecting it to remain valid for the
subgraph. This fails for \textsc{Dominating Set}, since a vertex in the subgraph could still be dominated by a vertex outside the subgraph.

\noindent It is shown that the general shifting technique can be used to obtain a PTAS for \textsc{Dominating Set}. The interesting part is that 
in order to properly analyse the solution, one must make the slices overlap on two levels. We refer to Marzban and Gu \cite{dominatingsetptas} for
the explanation as to why the last is true and how to obtain the $(1 + 2 / \ell)$ approximation ratio.

\subsubsection{Treewidth}

\noindent According to Diestel~\cite[pp. 354-355]{diestel2000graph} the notions of 
tree decomposition and treewidth were introduced by 
Halin~\cite{halin1976s} under the name of $S$-functions and Robertson and Seymour ~\cite{ROBERTSON1986309}.
We give brief definitions of these concepts and then discuss bounded local treewidth and linear local 
treewidth. The last two notions are important for the main theorem we work with, namely
Bumpus et al.~\cite[Theorem 1.7]{bumpus_et_al:LIPIcs.SWAT.2024.19}.

\noindent From Diestel~\cite[Section 12.3]{diestel2000graph} we have the following definition of a 
tree decomposition.

\refstepcounter{definition} % Increment counter after the definition content
\begin{mydefinition}[Tree Decomoposition]{Definition}
    \label{def:tree-decomp}

    Let $G$ be a graph, $T$ a tree, and let $\mathcal{V} = (V_t)_{t \in T}$ be a family of vertex sets
    $V_t \subseteq V(G)$ indexed by the vertices $t$ of $T$.
    The pair $(T, \mathcal{V})$ is called a \emph{tree decomposition} of $G$ if it satisfies
    the following conditions:

    \begin{itemize}
        \item[(T1)] $V(G) = \bigcup_{t \in T} V_t$.
        \item[(T2)] For every edge $e \in E(G)$, there exists a $t \in T$ such that both ends of $e$ lie in $V_t$.
        \item[(T3)] If $t_1, t_2, t_3 \in T$ satisfy $t_2$ lies on the unique path between $t_1$ and $t_3$ in $T$, then 
        \[
            V_{t_1} \cap V_{t_3} \subseteq V_{t_2}.
        \]
    \end{itemize}

\end{mydefinition}

The \textit{width} of a tree decomposition $(T, V)$ is the size of its largest set $V_t$ minus one.
The \textit{treewidth} $\operatorname{tw}(G)$ of a graph $G$ is the minimum width among all possible
tree decompositions of $G$. 

\refstepcounter{definition} % Increment counter after the definition content
\begin{mydefinition}[Bounded local treewidth]{Definition}
    \label{def:bounded-local-treewidth}

    A graph $G$ has bounded local treewidth if the subgraph induced by vertices at distance 
    at most $d$ is a function of $d$ ($f : \mathbb{N} \to \mathbb{R}$) and not $n$.

\end{mydefinition}

\noindent Furthermore, if there exists $\lambda \in \mathbb{R}$, such that 
$f$ can be defined as $f : r \to \lambda \cdot r$, then $G$ would have linear local treewidth.

\noindent Building on the work of Eppstein~\cite{eppstein2000diameter}, 
Demaine and Hajiaghayi~\cite{demaine2003equivalence} prove that apex-minor-free graphs 
have linear local treewidth. Apex graphs are graphs that can be made planar by the removal 
of a single vertex. From this follows that planar graphs also have linear local treewidth.

\subsubsection{Linear Programming and Randomized Rounding}

One way of approximating solutions is done through Linear Programming (LP). For a more detailed review of \textsc{LP}, 
the reader can consult Korte and Vygen \cite[Chapter 3]{Korte2007CombinatorialOT}.
One solves a linear relaxation, 
which provides fractional values as solutions. Afterwards, the fractional solution 
is rounded to an integral one, but rather than doing it 
deterministically, this process is done in a randomized fashion.
This technique is called \textit{randomized rounding}.
This framework provides a way to obtain certified algorithms, for a more in depth look 
for randomized rounding the reader should consult Makarychev and Makarychev \cite{Makarychev_Makarychev_2021}. 

\subsection{Beyond the Worst-Case Analysis of Algorithms}\label{BWCA-section}

In this section we explore perturbation-resilience, also known as \textit{$\gamma$-stability} or Bilu-Linial stability. 
The authors refer to the original paper of the two authors Bilu and Linial \cite{bilu2012stable} as well as a survey 
on the matter by Makarychev and Makarychev \cite{makarychev201713}. In a later work, Makarychev and Makarychev define 
\textit{$\gamma$-certified algorithms} \cite{Makarychev_Makarychev_2021}. In the final paragraph, we take a look 
back at combinatorial optimization problems through the lens of constraint satisfaction.

The following definitions for $\gamma$-perturbation are for edge-optimization and vertex-optimization problems, respectively. 
Afterwards, we are going to define stability and certified algorithms for vertex-optimization problems only.

\refstepcounter{definition} % Increment counter after the definition content
\begin{mydefinition}[$\gamma$-perturbation for Edge-Optimization problems]{Definition}
    \label{gpeop}

    Consider a weighted graph $G = (V, E, w)$ with a set of edge weights $w_e$. An instance $G' = (V, E, w')$ is a 
    $\gamma$-perturbation ($\gamma \in \mathbb{R_{\geq \text{1}}}$) of $G$ if $w(e) \leq w'(e) \leq \gamma \cdot w(e)$; that is, if we can 
    obtain a perturbed instance from the original by multiplying the weight of each edge by a number between $1$ and $\gamma$ 
    (the number may vary for each edge).

\end{mydefinition}

\noindent From now on, the definitions will concentrate on Vertex-Optimization problems.

\refstepcounter{definition} % Increment counter after the definition content
\begin{mydefinition}[ $\gamma$-perturbation for Vertex-Optimization problems]{Definition}
    \label{gpvop}

    Consider a weighted graph $(G, w)$. For any $\gamma \in \mathbb{R_{\geq \text{1}}}$ a $\gamma$-perturbation of the weight function 
    $w : V \to \mathbb{R}$ is a function $w' : V \to R$ satisfying $w(v) \leq w'(v) \leq \gamma \cdot w(v) \; \forall v \in V$.

\end{mydefinition}

\refstepcounter{definition} % Increment counter after the definition content
\begin{mydefinition}[$\gamma$-stability]{Definition}
    \label{gs}

    For any $\gamma \in \mathbb{R_{\geq \text{1}}}$, a $\gamma$-stable instance $(G, w)$ of a \textit{vertex-minimization} problem 
    $\Pi$  is an instance admitting a unique optimal solution \textit{S} which remains optimal even under $\gamma$-perturbations of 
    $(G, w)$.

\end{mydefinition}

\refstepcounter{definition} % Increment counter after the definition content
\begin{mydefinition}[Certified Algorithm]{Definition}
    \label{ca}

    A $\gamma$-certified solution to an instance $(G, w)$ of a weighted vertex-optimization problem $\Pi$ is a pair $(S, w')$ 
    where $w'$ is a $\gamma$-perturbation of $w$ and $S$ is an optimal solution on $(G, w')$. A $\gamma$-certified algorithm 
    for $\Pi$ maps instances of $\Pi$ to $\gamma$-certified solutions. 

\end{mydefinition}

\refstepcounter{definition} % Increment counter after the definition content
\begin{mydefinition}[Combinatorial Optimization problems (Constraint Satisfaction)]{Definition}
    \label{cosp}

    An instance of a \textit{combinatorial optimization} problem is specified by a set of feasible solutions $\mathcal{S}$ (the solution space) 
    a set of constraints $\mathcal{C}$ and constraint weights $w_c > 0$ for $c \in \mathcal{C}$. Typically the solution space is 
    exponential in size (as is the case with \textsc{MWFVS} with the number of cycles in a graph) and is not provided explicitly. 
    We say that a feasible solution $s \in \mathcal{S}$ satisfies a constraint $c \in \mathcal{C}$ if $c(s) = 1$.  

    \noindent Consider the minimization and maximization objectives.

    \begin{itemize}[noitemsep, topsep=0pt]
        \item The minimization objective is to minimize the total weight of the unsatisfied constraints: find $s \in \mathcal{S}$ 
        that minimizes $\sum\limits_{c \in C} w_c \cdot (1 - c(s)) = w(\mathcal{C}) - val_{\mathcal{I}}(s)$, where 
        $w(\mathcal{C}) = \sum\limits_{c \in \mathcal{C}} w(c)$ is the total weight of the constraints.  
        \item The maximization objective is to maximize the total weight of the satisfied constraints: find $s \in \mathcal{S}$ that 
        maximizes $val_{\mathcal{I}}(s) = \sum\limits_{c \in \mathcal{C}} w(c) \cdot c(s)$.
    \end{itemize}

\end{mydefinition}

\noindent Now we familiarize the reader with the two ways of designing certified algorithms as presented in \cite{Makarychev_Makarychev_2021}. 
The first is a general framework that (1) starts with an arbitrary solution and (2) iteratively improves it. The improvements in step 2,
however, are not necessarily local, though it may look like a local search technique. The following is taken from the paper on certified 
algorithms where it is presented as Task 5.13.

\refstepcounter{definition} % Increment counter after the definition content
\begin{mydefinition}[General framework for $\gamma$-certified algorithms]{Task}
    \label{gfca}

    Assume we are given an instance $\mathcal{I}(\mathcal{S}, \mathcal{C}, w)$, a partition of its constraints 
    $\mathcal{C} = \mathcal{C}_{1} \cup \mathcal{C}_{2}$ and a parameter $\gamma$. The task is to either:

    \begin{itemize}[left=0pt, labelsep=5pt, itemsep = 3pt, topsep=3pt]

        \item Option 1: find a better $s \in \mathcal{S}$, such that 
        $\gamma \cdot \sum\limits_{c \in \mathcal{C}_1} w_c c(s) > \sum\limits_{c \in \mathcal{C}_2} w_c (1 - c(s))$, or

        \item Option 2: to report that for every $s \in \mathcal{S}$:
        $\sum\limits_{c \in \mathcal{C}_1} w_c c(s) \leq \sum\limits_{c \in \mathcal{C}_2} w_c (1 - c(s))$.

    \end{itemize}

\end{mydefinition}

\noindent In this procedure, $\mathcal{C}_1$ and $\mathcal{C}_2$ are the sets of constraints that are currently unsatisfied and satisfied,
respectively. If $\gamma = 1$, then Option 1 would try to find a solution where the weight of the unsatisfied constraints is strictly 
greater than the weight of the unsatisfied by $s$. Therefore, Option 1 finds a better solution than the current one, while Option 2 
reports that there is no solution better than $s$. The options are not mutually exclusive. 

\noindent For the second approach, we refer the reader to the paper of Makarychev and Makarychev \cite{Makarychev_Makarychev_2021} 
as the explanation is quite long and needs to be understood with the examples given.
