\section{Preliminaries}

 In this section, we provide the reader with the necessary information in order to follow the paper. We start 
with a reminder of Graph Theory. After that, we move to more advanced definitions in the field of 
Combinatorial Optimization. Finally, we get on topic by introducing perturbation resilience and certified 
algorithms from the field of Beyond the Worst-Case Analysis of Algorithms.

\subsection{Graph Theory} 

In this section, the authors refer to Bondy and Murty \cite{bondy1976graph}.
A \textit{graph} $G$ is an ordered pair denoted as $(V(G), E(G))$.
The set $V(G)$ is called a set of \textit{vertices} and the set $E(G)$ is a set of \textit{edges}.
The incidence function $\psi_G$ associates each edge with an unordered pair of 
(not necessarily unique) vertices. The ordered pair and the incidence function define the graph $G$.
We are going to use $n$ as the cardinality 
of the set $V$ and $m$ for the set of edges $E$. With each edge $e$ of G, let there be associated 
a real number $w(e)$, called its \textit{weight}. Then G, together with the weighting function 
$w : E \to \mathbb{R}$, is called a \textit{weighted graph}, and denoted $(G, w)$.

 A graph can be \textit{embedded in the plane}, or is \textit{planar}, if it can be drawn on the 
plane in a way that edges intersect each other only at their ends. Such a drawing is called a 
\textit{planar embedding} of the graph. A graph $G$ is called \textit{outerplanar} if it has a 
planar embedding $\widetilde{G}$ in which all the vertices lie on the boundary of the outer face. 
This is also called a \textit{1-outerplanar graph}. Two forbidden minors of that class are the 
$K_4$ and $K_{2, 3}$ graphs. In the next subsection, we familiarize the reader with Baker's approach 
\cite{Baker}. Here, we define an \textit{$\ell$-outerplanar} to be a graph that has a planar embedding in which 
the vertices belong to at most $\ell$ concentric layers. Every planar graph is \textit{$\ell$-outerplanar} for 
some $\ell$. Given a graph $G$, we look for the \textit{$\ell$-outerplanar} embedding of $G$ for which $\ell$ is minimal.

Let \( G = (V, E) \) be a graph and let \( v \in V \).
The \emph{closed \( m \)-neighbourhood} of \( v \), denoted by \( N^{m}_{G}[v] \),
is the set of all vertices in \( G \) that are at distance at most \( r \) from \( v \):
\[
N^{m}_{G}[v] = \{ u \in V \mid \operatorname{dist}_G(u, v) \leq m \}.
\]

\subsection{Combinatorial Optimization}

In this section, we refer to the book on Combinatorial Optimization by Korte and Vygen \cite{Korte2007CombinatorialOT} and 
Williamson and Shmoys \cite{williamson2011design}. Some definitions can be traced to the end of the book by Cygan et al. \cite{cygan2015parameterized}. 

\subsubsection{NP-Complete Problems: Definitions and Variants}

Two problems are of interest, namely the Feedback Vertex Set and the $r$-Dominating Set. The latter 
is a generalization of the Dominating Set problem.
All of those problems belong to the class of \textbf{NP-complete} problems. 
The decision variant of the FVS problem can be defined as:

\refstepcounter{definition}
\begin{mydefinition}[Feedback Vertex Set (\textbf{FVS})]{Definition}

    \label{FVS}
    \textbf{Input:}
    A graph $G$ and an integer $k$.

    \textbf{Question:}
    Does there exist a set $X$ of at most $k$ vertices of $G$ such that $G - X$ is a forest?
    
\end{mydefinition}

 The weighted optimization version of the problem can be defined as:

\refstepcounter{definition}
\begin{mydefinition}[ Minimum Weight Feedback Vertex Set (\textbf{MWFVS})]{Definition}
    \label{MWFVS}

    \textbf{Instance:}
    \begin{itemize}[noitemsep, topsep=0pt]
        \item An undirected weighted graph $(G, w)$, where $G = (V, E)$ and $w: V \to \mathbb{R}$.
    \end{itemize}
    \textbf{Task:}
    Find a vertex set $X \subseteq V$ such that:
    \begin{itemize}[noitemsep, topsep=0pt]
        \item \( G \setminus X \) is acyclic (i.e., a forest)
        \item The sum of the weights of the vertices in $X$ is minimized.
    \end{itemize}

\end{mydefinition}


The suffix 'BCL' in the definitions of the problems FVS-BCL and MWFVS-BCL indicates that they 
pertain to the bounded cycle length variant.

\refstepcounter{definition}
\begin{mydefinition}[FVS-BCL]{Definition}
    \label{FVS-BCL}

    \textbf{Input:}
    A graph $G$, integer $k$ and an integer $\rho$.

    \textbf{Question:}
    Does there exist a set $X$ of at most $k$ vertices such that every cycle of length $\rho$ contains a vertex in $X$?

\end{mydefinition}

The following is the weighted version of the problem; we define it as an optimization task.

\refstepcounter{definition}
\begin{mydefinition}[MWFVS-BCL]{Definition}
    \label{MWFVS-BCL}

    \textbf{Instance:}
    \begin{itemize}[noitemsep, topsep=0pt]
        \item An undirected weighted graph $(G, w)$, where $G = (V, E)$ and $w: V \to \mathbb{R}$ and an integer $\rho$.
    \end{itemize}
    \textbf{Task:}
    Find a vertex set $X \subseteq V$ such that:
    \begin{itemize}[noitemsep, topsep=0pt]
        \item Every cycle in \( G \setminus X \) of length $\rho$ has a vertex in $X$.
        \item The sum of the weights of the vertices in $X$ is minimized.
    \end{itemize}

\end{mydefinition}

$r$-Dominating Set is a generalization of Dominating Set. Setting the parameter $r$ to one would 
transform the former problem into the latter.

\refstepcounter{definition}
\begin{mydefinition}[The \(r\)-Dominating Set Problem.]{Definition}
    \label{def:r-DS}

    \textbf{Input:}
    A graph $G = (V, E)$, an integer $k$ and an integer $r$.

    \textbf{Question:}
    Does there exist a subset $D \subseteq V$ of size at most $k$, such that every vertex
    $v \in V$ is within distance at most $r$ from some vertex in $D$; that is,

    \[
    \forall v \in V,\ \exists u \in D \text{ such that } \operatorname{dist}_G(u, v) \leq r.
    \]
\end{mydefinition}

The weighted version of the problem is defined as follows:

\refstepcounter{definition}
\begin{mydefinition}[The Weighted \(r\)-Dominating Set Problem.]{Definition}
    \label{def:weighted-r-DS}

    \textbf{Input:}
    A graph $G = (V, E)$, a weight function $w: V \rightarrow \mathbb{N}$, an integer $W$, and an integer $r$.

    \textbf{Question:}
    Does there exist a subset $D \subseteq V$ such that the total weight of $D$ is at most $W$, and every vertex
    $v \in V$ is within distance at most $r$ from some vertex in $D$; that is,

    \[
    \sum_{u \in D} w(u) \leq W
    \quad \text{and} \quad
    \forall v \in V,\ \exists u \in D \text{ such that } \operatorname{dist}_G(u, v) \leq r.
    \]
\end{mydefinition}


\subsubsection{Approximation Algorithms and Complexity Classes}

In the previous section all of the problems were NP-complete. In order to cope with the hardness 
of those problems, one can turn to \textit{approximation algorithms}.
Let $\Pi$ be an optimization problem with nonnegative weights 
and $q \geq 1$.
A \textit{$q$-factor approximation algorithm} for $\Pi$ is a polynomial-time algorithm $A$ for $\Pi$, 
such that \[\frac{1}{q} \cdot OPT(I) \leq A(I) \leq q \cdot OPT(I)\] for all instances $I$ of $\Pi$.
The first inequality shown is true for maximization problems, while the second one holds for minimization problems.
We say $A$ has a performance ratio of \textit{q}. If a problem falls into that category, we say that it is \textsc{APX-complete}. 

The previous paragraph introduced the class of problems \textsc{APX} in the context
of approximation algorithms. Now, we introduce another important class: \textsc{PTAS},
which consists of algorithms that run in polynomial time and produce solutions arbitrarily close to optimal, depending on a trade-off parameter.

\refstepcounter{definition}
\begin{mydefinition}[ Polynomial-Time Approximation Scheme (PTAS)]{Definition}
    \label{PTAS}
    
    A polynomial-time approximation scheme (PTAS) is a family of algorithms ${A_{\epsilon}}$ where there is an algorithm for each $\epsilon > 0$, 
    such that $A_{\epsilon}$ is a $(1 + \epsilon)$-approximation algorithm (for minimization problems). The running time of the algorithm $A_{\epsilon}$ 
    is polynomial, but can depend arbitrarily on $1/\epsilon$. 

\end{mydefinition}

The dependence, mentioned in Def.~\ref{PTAS}, on $\frac{1}{\epsilon}$ could be exponential
or even worse.
Thus an algorithm running in time $O(n^{1/\epsilon})$ counts as a PTAS.

Every problem with a PTAS is also in APX. The relation between these two classes is similar to the one between 
\textsc{P} and \textsc{NP}. For more on the topic, such as APX-completeness,
L-reductions and the PCP-theorem, we refer to Korte and Vygen \cite{Korte2007CombinatorialOT}.

An important distinction in the complexity zoo is made in Cesati and
Trevisan \cite{cesati1997efficiency}. To the best of the knowledge of the author, 
Cesati and Trevisan first describes what an efficient PTAS is.

\refstepcounter{definition}
\begin{mydefinition}[Efficient Polynomial-Time Approximation Scheme (EPTAS)]{Definition}
    \label{def:EPTAS}
    
    An efficient PTAS yields a $(1 + \epsilon)$ approximation scheme and has a running time 
    of $f(\epsilon) \cdot n^{c}$ where $f$ is an arbitrary function and $c$ is a constant. 

\end{mydefinition}

\subsubsection{Baker's approach}
\label{subsection:baker}

This subsection presents the Shifting Technique, originally introduced in Baker's seminal 
paper~\cite{Baker}. The technique outlines a general algorithm that partitions the graph 
into a disjoint union of vertex levels. By analysing slices of these 
levels and, more specifically, the overlap between these slices, one obtains an approximation ratio for the solution to the optimization 
problem. The slices make up several levels that are specifically chosen for a problem and it should hold that an exact solution 
can be found in each one slice. It must also hold that this solution can be found in optimal time. 

There is also another way to view this approach. Instead of analysing the overlap between slices, one could partition the graph 
by removing said overlap. In this way, the resulting disjoint union may not cover the entire 
optimal solution, but it can be shown that the deviation from optimality is bounded. \
This approach works for hereditary maximization problems like \textsc{Independent Set}, \textsc{Max-Cut}, 
\textsc{Maximum P-Matching}, etc. 

The following section presents one example application.
It focuses on the general Shifting Technique, using the \textsc{Vertex Cover} problem 
as an illustrative case. 
This example is explored in great detail, as both the problem and the technique 
closely resemble the approach required for solving FVS-BCL.

It is important to highlight that the general Shifting Technique is more powerful than 
the vertex-removal partitioning. For problems like Dominating Set, the latter technique does not 
yield a PTAS.

However, using the general shifting technique, one can obtain a 
PTAS for \textsc{Dominating Set} in planar graphs. This was done by Marzban and Gu \cite{dominatingsetptas}. They designed a PTAS with an 
approximation ratio of $(1 + 2/\ell)$. The two in the approximation 
ratio appears because of the overlap on two levels.

What follows is a brief explanation of Baker's shifting technique with \textsc{Vertex Cover} as an example.

\begin{algorithm}[H]
    \caption{Baker's shifting technique}
    \label{alg:baker}
    \begin{algorithmic}[1]
    \REQUIRE Planar graph $G = (V, E)$, parameter $\ell$
    \ENSURE $(1 + \epsilon)$-approximation for \textsc{Vertex Cover}
    \STATE Perform \textsc{BFS} from some arbitrary vertex $r$
    \STATE $S \leftarrow \emptyset$

    $i$: \textit{shift}; $j$: \textit{slice}

    \FOR{each $i = 0$ to $\ell - 1$}
        \STATE Let $G_{i, j}$ be the subgraph induced on vertices at levels $j \cdot \ell + i$ through $(j+1) \cdot \ell + i$ for $0 \leq i < \ell$. \label{line:4}
        \STATE $\forall j \text{ compute }  S_{i, j}$, the min. \textsc{VC} of $G_{i, j}$.
        \STATE $\forall j \text{ let } S_i = \bigcup_{j} S_{i, j}$
        \STATE $S \leftarrow S \cup S_i$
    \ENDFOR
    \RETURN $S_{i*}$ from $S$ with minimum cardinality
    \end{algorithmic}
\end{algorithm}

Analysis of the algorithm:

 Let \( V_i \) be the set of vertices at levels \( i \mod \ell \):
\[ V_i = \{ v \in V \mid \text{level}(v) \equiv i \mod \ell \} \]

 Let $OPT_i$ denote $OPT \cap V_i$. We notice that $OPT_i$ are disjoint and $OPT = \bigcup_{i} OPT_i$. 
Therefore, we can make the following argument: 

\begin{enumerate}
    \item $\exists q: |OPT_q| \leq \frac{1}{\ell} \cdot OPT = \epsilon |OPT|$
    \item $S_q \leq \sum\limits_{j} S_{q, j}$, for some shift $q$ we have this inequality because in step 5. of the algorithm 
    we define the set to be a union over all slices and some vertices may appear twice in the boundary layers. 
    \item $\sum\limits_{j} S_{qj} \leq \sum\limits_{j} |OPT \cap V(G_{q, j})|$, we know that $S_{q, j}$ is a min. \textsc{VC} for $G_{q, j}$, while the 
    optimal solution may choose different vertices, especially on the boundary for the global optimality of the solution.
    \item $\sum\limits_{j} |OPT \cap V(G_{q, j})| \leq |OPT| + |OPT_q|$, if we consider the graphs $\{G_{q, j}\}$, then we can argue that 
    each vertex appears once, except those at levels $q \mod \ell$, which appear twice. 
\end{enumerate}

 From the first, second and fourth step we can conclude that: \[S_q \leq |OPT| + |OPT_q| \leq (1 + \epsilon) \cdot |OPT|\]

\subsubsection{Treewidth}

 According to Diestel~\cite[pp. 354-355]{diestel2000graph} the notions of 
tree decomposition and treewidth were introduced by 
Halin~\cite{halin1976s} under the name of $S$-functions and Robertson and Seymour ~\cite{ROBERTSON1986309}.
We give brief definitions of these concepts and then discuss bounded local treewidth and linear local 
treewidth. The last two notions are important for the main theorem we work with, namely
Bumpus et al.~\cite[Theorem 1.7]{bumpus_et_al:LIPIcs.SWAT.2024.19}.

 From Diestel~\cite[Section 12.3]{diestel2000graph} we have the following definition of a 
tree decomposition.

\refstepcounter{definition} % Increment counter after the definition content
\begin{mydefinition}[Tree Decomoposition]{Definition}
    \label{def:tree-decomp}

    Let $G$ be a graph, $T$ a tree, and let $\mathcal{V} = (V_t)_{t \in T}$ be a family of vertex sets
    $V_t \subseteq V(G)$ indexed by the vertices $t$ of $T$.
    The pair $(T, \mathcal{V})$ is called a \emph{tree decomposition} of $G$ if it satisfies
    the following conditions:

    \begin{itemize}
        \item[(T1)] $V(G) = \bigcup_{t \in T} V_t$.
        \item[(T2)] For every edge $e \in E(G)$, there exists a $t \in T$ such that both ends of $e$ lie in $V_t$.
        \item[(T3)] If $t_1, t_2, t_3 \in T$ satisfy $t_2$ lies on the unique path between $t_1$ and $t_3$ in $T$, then 
        \[
            V_{t_1} \cap V_{t_3} \subseteq V_{t_2}.
        \]
    \end{itemize}

\end{mydefinition}

The \textit{width} of a tree decomposition $(T, V)$ is the size of its largest set $V_t$ minus one.
The \textit{treewidth} $\tw(G)$ of a graph $G$ is the minimum width among all possible
tree decompositions of $G$. 

\refstepcounter{definition} % Increment counter after the definition content
\begin{mydefinition}[Bounded local treewidth]{Definition}
    \label{def:bounded-local-treewidth}

    A graph $G$ has bounded local treewidth if the subgraph induced by vertices at distance 
    at most $d$ is a function of $d$ ($f : \mathbb{N} \to \mathbb{R}$) and not $n$.

\end{mydefinition}

 Furthermore, if there exists $\lambda \in \mathbb{R}$, such that 
$f$ can be defined as $f : r \to \lambda \cdot r$, then $G$ would have linear local treewidth.

 Building on the work of Eppstein~\cite{eppstein2000diameter}, 
Demaine and Hajiaghayi~\cite{demaine2003equivalence} prove that apex-minor-free graphs 
have linear local treewidth. Apex graphs are graphs that can be made planar by the removal 
of a single vertex. From this follows that planar graphs also have linear local treewidth.

\subsubsection{Linear Programming and Randomized Rounding}

One way of approximating solutions is done through Linear Programming (LP). For a more detailed review of \textsc{LP}, 
the reader can consult Korte and Vygen \cite[Chapter 3]{Korte2007CombinatorialOT}.
One solves a linear relaxation, 
which provides fractional values as solutions. Afterwards, the fractional solution 
is rounded to an integral one, but rather than doing it 
deterministically, this process is done in a randomized fashion.
This technique is called \textit{randomized rounding}.
This framework provides a way to obtain certified algorithms, for a more in depth look 
for randomized rounding the reader should consult Makarychev and Makarychev \cite{Makarychev_Makarychev_2021}. 

\subsection{Beyond the Worst-Case Analysis of Algorithms}\label{BWCA-section}

In this section we explore perturbation-resilience, also known as \textit{$\gamma$-stability} or Bilu-Linial stability. 
The authors refer to the original paper of Bilu and Linial \cite{bilu2012stable} as well as a survey 
by Makarychev and Makarychev \cite{makarychev201713}. In a later work, Makarychev and Makarychev define 
\textit{$\gamma$-certified algorithms} \cite{Makarychev_Makarychev_2021}.

The following definitions for $\gamma$-perturbation are for edge-optimization 
and vertex-optimization problems, respectively. 
Subsequently, the notions of stability and certified algorithms are introduced 
specifically for vertex-optimization problems.

\refstepcounter{definition}
\begin{mydefinition}[$\gamma$-perturbation for Edge-Optimization problems]{Definition}
    \label{gpeop}

    Consider a weighted graph $G = (V, E, w)$ with a set of edge weights $w_e$. An instance $G' = (V, E, w')$ is a 
    $\gamma$-perturbation ($\gamma \in \mathbb{R_{\geq \text{1}}}$) of $G$ if $w(e) \leq w'(e) \leq \gamma \cdot w(e)$; that is, if we can 
    obtain a perturbed instance from the original by multiplying the weight of each edge by a number between $1$ and $\gamma$ 
    (the number may vary for each edge).

\end{mydefinition}

 From now on, the definitions will concentrate on Vertex-Optimization problems.

\refstepcounter{definition} % Increment counter after the definition content
\begin{mydefinition}[ $\gamma$-perturbation for Vertex-Optimization problems]{Definition}
    \label{gpvop}

    Consider a weighted graph $(G, w)$. For any $\gamma \in \mathbb{R_{\geq \text{1}}}$ a $\gamma$-perturbation of the weight function 
    $w : V \to \mathbb{R}$ is a function $w' : V \to R$ satisfying $w(v) \leq w'(v) \leq \gamma \cdot w(v) \; \forall v \in V$.

\end{mydefinition}

\refstepcounter{definition} % Increment counter after the definition content
\begin{mydefinition}[$\gamma$-stability]{Definition}
    \label{gs}

    For any $\gamma \in \mathbb{R_{\geq \text{1}}}$, a $\gamma$-stable instance $(G, w)$ of a \textit{vertex-minimization} problem 
    $\Pi$  is an instance admitting a unique optimal solution \textit{S} which remains optimal even under $\gamma$-perturbations of 
    $(G, w)$.

\end{mydefinition}

\refstepcounter{definition} % Increment counter after the definition content
\begin{mydefinition}[Certified Algorithm]{Definition}
    \label{ca}

    A $\gamma$-certified solution to an instance $(G, w)$ of a weighted vertex-optimization problem $\Pi$ is a pair $(S, w')$ 
    where $w'$ is a $\gamma$-perturbation of $w$ and $S$ is an optimal solution on $(G, w')$. A $\gamma$-certified algorithm 
    for $\Pi$ maps instances of $\Pi$ to $\gamma$-certified solutions. 

\end{mydefinition}

\subsection{r-Dominating Set; Exact algorithm and PTAS}

For FVS-BCL we will give an algorithm that solves the problem on graphs of bounded treewidth. 
For Dominating Set and its generalizations there are already existing solutions one can use. 
The r-Dominating Set problem is one generalization of Dominating Set. We mention an algorithm 
which solves the generalized version. In this work the parameter $r$ is considered to be 
constant.

There is an algorithm that solves r-Dominating Set using dynamic programming which is realized 
by Borradaile and Le~\cite[Theorem 1, Appendix B.]{borradaile2015optimal}. It is a generalization 
of the work done in van Rooij et al.~\cite{van2009dynamic}. As it is argued in Borradaile and Le
\cite[Appendix B.]{borradaile2015optimal}, the running time needed to solve r-Dominating Set 
is $(2r + 1)^{\tw + 1} \cdot \tw^{2} \cdot n$. 

We showed in subsection~\ref{subsection:baker} how one can use an exact algorithm 
for graphs of bounded treewidth to get an approximation in a planar graph. In 
Borradaile and Le~\cite{borradaile2015optimal} it is mentioned that one can use Baker's technique 
to obtain a PTAS. In the MIT lecture notes of \cite{demaine2011lecture9}, there is an explanation 
of how to get to that approximation. Essentially, instead of two layers of overlap between 
subgraphs, one would have to increase that overlap to $r+1$. This technique will yield results 
only for sufficiently small values for the parameter $r$.
