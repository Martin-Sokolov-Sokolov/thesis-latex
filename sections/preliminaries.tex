\section{Preliminaries}

\noindent In this section, we provide the reader with the necessary information in order to follow the paper. We start 
off with a reminder on Graph Theory. After that, we move to more advanced definitions in the field of 
Combinatorial Optimization. Finally, we get on topic by introducing perturbation resilience and certified 
algorithms from the field of Beyond the Worst-Case Analysis of Algorithms.

\subsection{Graph Theory}

\noindent In this section, the authors refer to Bondy and Murty \cite{bondy1976graph}.
A \textit{graph} $G$ is an ordered pair denoted as $(V(G), E(G))$.
The set $V(G)$ is called a set of \textit{vertices} and the set $E(G)$, a set of \textit{edges}.
The incidence function $\psi_G$ associates each edge with an unordered pair of 
(not necessarily unique) vertices. The ordered pair and the incidence function define the graph $G$.
We are going to use $n$ as the cardinality 
of the set $V$ and $m$ for the set of edges $E$. With each edge $e$ of G, let there be associated 
a real number $w(e)$, called its \textit{weight}. Then G, together with the weighting function 
$w : E \to \mathbb{R}$, is called a \textit{weighted graph}, and denoted $(G, w)$.

\noindent A graph is can be \textit{embedded in the plane}, or is \textit{planar} if it can be drawn on the 
plane in a way that edges intersect each other only at their ends. Such a drawing is called a 
\textit{planar embedding} of the graph. A graph $G$ is called \textit{outerplanar} if it has a 
planar embedding $\widetilde{G}$ in which all the vertices lie on the boundary of the outer face. 
This is also called a \textit{1-outerplanar graph}. Two forbidden minors of that class are the 
$K_4$ and $K_{2, 3}$ graphs. In the next subsection we familiarize the reader with Baker's approach 
\cite{Baker}. Here we define a \textit{k-outerplanar} to be a graph that has a planar embedding in which 
the vertices belong to at most $k$ concentric layers. Every planar graph is \textit{k-outerplanar} for 
some $k$. Given a graph $G$, we look for \textit{k-outerplanar} embedding of $G$ for which $k$ is minimal.

\subsection{Combinatorial Optimization}

\noindent In this section, we refer to the book on Combinatorial Optimization by Korte and Vygen \cite{Korte2007CombinatorialOT} and 
Williamson and Shmoys \cite{williamson2011design}. Some definitions can be traced to the end of the book by Cygan et al. \cite{cygan2015parameterized}. 
We are going to be looking at two problems, namely the \textsc{Feedback Vertex Set} and \textsc{Travelling Salesman Problem}. 
Both of those problems belong to the class of \textbf{NP-complete} problems. The former was also part of Karp's 
21 problems \cite{Karp1972}. The decision variant of the \textsc{FVS} problem can be defined as:

\begin{mydefinition}[Feedback Vertex Set, label={def:FVS}]

    \textbf{Input:}
    A graph $G$ and an integer $k$.

    \textbf{Question:}
    Does there exist a set $X$ of at most $k$ vertices of $G$ such that $G - X$ is a forest?

\end{mydefinition}

\noindent The weighted optimization version of the problem can be defined as:

\begin{mydefinition}[Minimum Weight Feedback Vertex Set, label={def:MWFVS}]

    \textbf{Instance:}
    \begin{itemize}[noitemsep, topsep=0pt]
        \item An undirected weighted graph $(G, w)$, where $G = (V, E)$ and $w: V \to \mathbb{R}$.
    \end{itemize}
    \textbf{Task:}
    Find a vertex set $X \subseteq V$ such that:
    \begin{itemize}[noitemsep, topsep=0pt]
        \item \( G \setminus X \) is acyclic (i.e., a forest)
        \item The sum of the weights of the vertices in $X$ is minimized.
    \end{itemize}

\end{mydefinition}

\noindent The other problem we inspect is an edge-optimization problem, namely the \textsc{Travelling Salesman Problem} (TSP).

\begin{mydefinition}[Travelling Salesman Problem, label={def:TSP}]

    \textbf{Instance:}
    \begin{itemize}[noitemsep, topsep=0pt]
        \item A set of cities $C = \{c_1, c_2, \ldots, c_n\}$.
        \item A distance function $w: C \times C \to \mathbb{R}$ that gives the distance between each pair of cities.
    \end{itemize}
    \textbf{Task:}
    Find a permutation $\pi$ of the cities such that:
    \begin{itemize}[noitemsep, topsep=0pt]
        \item The total distance travelled is minimized, i.e., minimize 
        \begin{align*}
            \sum_{i=1}^{n-1} w(c_{\pi(i)}, c_{\pi(i+1)}) + w(c_{\pi(n)}, c_{\pi(1)}).
        \end{align*}
    \end{itemize}

\end{mydefinition}

\noindent As we mentioned, both of the problems are \textbf{NP-complete}, so we turn to \textit{approximation algorithms} 
in order to cope with the hardness of the problems. Let $\Pi$ be an optimization problem with nonnegative weights 
and $k \geq 1$.
A \textit{k-factor approximation algorithm} for $\Pi$ is a polynomial-time algorithm $A$ for $\Pi$, 
such that \[\frac{1}{k} \times OPT(I) \leq A(I) \leq k \times OPT(I)\] for all instances $I$ of $\Pi$.
The first inequality shown is true for maximization problems, while the second one holds for minimization problems.
We say $A$ has performance ratio \textit{k}. 
This definition is for algorithms for constant-factor approximation or algorithms for \textbf{NP} optimization problems that belong to the class \textbf{APX} 
(an abbreviation for "approximable"). A polynomial-time approximation scheme (PTAS) is a family of algorithms 
${A_{\epsilon}}$ where there is an algorithm for each $\epsilon > 0$, such that $A_{\epsilon}$, is a $(1 + \epsilon)$-
approximation algorithm (for minimization problems). The running time of the algorithm $A_{\epsilon}$ is polynomial, 
but can depend arbitrarily on $1/\epsilon$. This dependence could be exponential or even worse.

\begin{mydefinition}[ Polynomial-Time Approximation Scheme (PTAS), label={def:PTAS}] 
    
    A polynomial-time approximation scheme (PTAS) is a family of algorithms ${A_{\epsilon}}$ where there is an algorithm for each $\epsilon > 0$, 
    such that $A_{\epsilon}$ is a $(1 + \epsilon)$-approximation algorithm (for minimization problems). The running time of the algorithm $A_{\epsilon}$ 
    is polynomial, but can depend arbitrarily on $1/\epsilon$. This dependence could be exponential or even worse.

\end{mydefinition}

\subsubsection{Baker's approach}

\noindent In this subsection, we are going to describe the Shifting technique. It is described in Baker's seminal paper \cite{Baker}.
What she describes is a general algorithm that partitions the graph into a disjoint union of levels of vertices. By analysing slices of these 
levels and more specifically the overlap between these slices, one obtains an approximation ratio for the solution of the optimization 
problem. The slices constitute a number of levels that are specifically chosen for a problem and it should hold that an exact solution 
can be found on one slice. It must also hold that this solution can be found in optimal time. 

\noindent There is also another way to view this approach. Instead of analysing the overlap between slices, one could partition the graph 
by removing said overlap. This way we get a disjoint union which does not sum up to the total solution, but we can argue that we did not stray 
away so much from the optimum solution. This approach works for hereditary optimization problems like \textsc{Independent Set}, \textsc{Max-Cut}, 
\textsc{Maximum P-Matching}, etc. 

\noindent We are going to give two examples. The first is the general shifting technique and the example problem for it will be \textsc{Vertex Cover}. 
Then we will explore the second perspective and take \textsc{Independent Set} as an example. It is important to note that the general technique is 
much more powerful than partitioning by means of removal of vertices. In the case of \textsc{Vertex Cover} we can still use the second approach 
and come to a PTAS, but the same does not hold for \textsc{Dominating Set}. However, using the general Shifting technique we can obtain a 
PTAS for \textsc{Dominating Set} in planar graphs. This was done by Marzban and Gu \cite{dominatingsetptas}. They designed a PTAS with a modified 
approximation ratio of $(1 + 2/k)$ in $O(2^k \times n)$ time. The two in the approximation ratio appears, because of the overlap needed 
for \textsc{Dominating Set} between slices which is two levels.

\noindent What follows is a brief explanation of Baker's Shifting technique with \textsc{Vertex Cover} as an example.

\begin{algorithm}[H]
    \caption{Baker's Shifting technique}
    \label{alg:baker}
    \begin{algorithmic}[1]
    \REQUIRE Planar graph $G = (V, E)$, parameter $k$
    \ENSURE $(1 + \epsilon)$-approximation for \textsc{Vertex Cover}
    \STATE Perform \textsc{BFS} from some arbitrary vertex $r$

    $i$: \textit{shift}; $j$: \textit{slice}

    \FOR{each $i = 0$ to $k-1$}
        \STATE Let $G_{i, j}$ be the subgraph induced on vertices at levels $j \times k + i$ through $(j+1) \times k + i$ for $0 \leq i < k$.
        \STATE Let $S_{i, j}$ be the min. \textsc{VC} of $G_{i, j}$.
        \STATE Let $S_i = \bigcup_{j} S_{i, j}$
    \ENDFOR
    \STATE $S_i$ with the minimum cardinality
    \end{algorithmic}
\end{algorithm}

\noindent Now we take a look at the second approach we described.

\begin{algorithm}[H]
    \caption{Baker's technique with removal}
    \label{alg:bakeremoval}
    \begin{algorithmic}[1]
    \REQUIRE Planar graph $G = (V, E)$, parameter $k$
    \ENSURE $(1 - \epsilon)$-approximation for \textsc{MIS}
    \STATE Perform \textsc{BFS} from some arbitrary vertex $r$
    \STATE Label each vertex according to its layer $i \mod k$.
    \FOR{each $i = 0$ to $k-1$}
        \STATE Remove the $i$-th layer and solve \textsc{MIS} optimally on the remaining graph
        \STATE Combine the solution with the $i$-th layer to form a feasible solution for the original graph
    \ENDFOR
    \STATE Return the best solution found among all iterations
    \end{algorithmic}
\end{algorithm}

\noindent Steps 2 through 5 hide many details, some of which we will now try to explain. 
By labelling the vertices of $G$ we obtain a partition, such that deleting any one part results in a graph 
of bounded treewidth $O(k)$. This allows for the optimal running time of the algorithm.

\noindent Analysis of the algorithm:

\begin{enumerate}
    \item for $k = 1/\epsilon$ compute partition $P_1, \dots , P_k$.
    \item for some $q$ ($1 \leq q \leq k)$, $|OPT \cap P_q| \leq \frac{1}{k} \times |OPT| = \epsilon \times |OPT|$, because 
    of the pigeonhole principle
    \item hence, $|OPT \cap (G - P_q)| \geq (1 - 1/k) \times |OPT| = (1 - \epsilon) \times |OPT|$
    \item return $max_i{|\text{\textsc{MIS}}(G - P_i)|}$
\end{enumerate}

\subsubsection{Linear Programming and Randomized Rounding}

One way of approximating solutions is done through Linear Programming (LP). For a more detailed review on Linear Programming 
the reader can consult Chapter 3 of Korte and Vygen \cite{Korte2007CombinatorialOT}. The algorithm we use solves a linear relaxation 
which provides fractional values as solutions. We then round this fractional solution to an integral one, but rather than doing it 
deterministically, we do the process randomly. This technique is called \textit{randomized rounding}.

\subsection{Beyond the Worst-Case Analysis of Algorithms}

In this section we explore perturbation-resilience, also known as \textit{$\gamma$-stability} or Bilu-Linial stability. 
The authors refer to the original paper of the two authors Bilu and Linial \cite{bilu2012stable} as well as a survey 
on the matter by Makarychev and Makarychev \cite{makarychev201613}. In a later work Makarychev and Makarychev define 
\textit{$\gamma$-certified algorithms} \cite{makarychev_et_al:LIPIcs.ITCS.2020.49}. In the final paragraph we take a look 
back at combinatorial optimization problems through the lens of constraint satisfaction.

The following definitions for $\gamma$-perturbation are for edge-optimization and vertex-optimization problems respectively. 
Afterwards, we are going to define stability and certified algorithms for vertex-optimization problems only.

\begin{mydefinition}[$\gamma$-perturbation for Edge-Optimization problems]

    Consider a weighted graph $G = (V, E, w)$ with a set of edge weights $w_e$. An instance $G' = (V, E, w')$ is a 
    $\gamma$-perturbation ($\gamma \in \mathbb{R_{\geq \text{1}}}$) of $G$ if $w(e) \leq w'(e) \leq \gamma \times w(e)$; that is, if we can 
    obtain a perturbed instance from the original by multiplying the weight of each edge by a number between $1$ and $\gamma$ 
    (the number may vary for each edge).

\end{mydefinition}

From now on, the definitions will concentrate on Vertex-Optimization problems.

\begin{mydefinition}[ $\gamma$-perturbation for Vertex-Optimization problems, label={def:gpvop}]

    Consider a weighted graph $(G, w)$. For any $\gamma \in \mathbb{R_{\geq \text{1}}}$ a $\gamma$-perturbation of the weight function 
    $w : V \to \mathbb{R}$ is a function $w' : V \to R$ satisfying $w(v) \leq w'(v) \leq \gamma \times w(v) \; \forall v \in V$.

\end{mydefinition}

\begin{mydefinition}[$\gamma$-stability, label={def:gs}]

    For any $\gamma \in \mathbb{R_{\geq \text{1}}}$, a $\gamma$-stable instance $(G, w)$ of a \textit{vertex-minimization} problem 
    $\Pi$  is an instance admitting a unique optimal solution \textit{S} which remains optimal even under $\gamma$-perturbations of 
    $(G, w)$.

\end{mydefinition}

\begin{mydefinition}[Certified Algorithm, label={def:ca}]

    A $\gamma$-certified solution to an instance $(G, w)$ of a weighted vertex-optimization problem $\Pi$ is a pair $(S, w')$ 
    where $w'$ is a $\gamma$-perturbation of $w$ and $S$ is an optimal solution on $(G, w')$. 

\end{mydefinition}

\begin{mydefinition}[Combinatorial Optimization problems (Constraint Satisfaction), label={def:cosp}]

    An instance of a \textit{combinatorial optimization} problem is specified by a set of feasible solutions $\mathcal{S}$ (the solution space) 
    a set of constraints $\mathcal{C}$ and constraint weights $w_c > 0$ for $c \in \mathcal{C}$. Typically the solution space is 
    exponential in size (as is the case with \textsc{MWFVS} with the number of cycles in a graph) and is not provided explicitly. 
    We say that a feasible solution $s \in \mathcal{S}$ satisfies a constraint $c \in \mathcal{C}$ if $c(s) = 1$.  

    \noindent Consider the minimization and maximization objectives.

    \begin{itemize}[noitemsep, topsep=0pt]
        \item The minimization objective is to minimize the total weight of the unsatisfied constraints: find $s \in \mathcal{S}$ 
        that minimizes $\sum_{c \in C} w_c \times (1 - c(s)) = w(\mathcal{C}) - val_{\mathcal{I}}(s)$, where 
        $w(\mathcal{C}) = \sum_{c \in \mathcal{C}} w(c)$ is the total weight of the constraints.  
        \item The maximization objective is to maximize the total weight of the satisfied constraints: find $s \in \mathcal{S}$ that 
        maximizes $val_{\mathcal{I}}(s) = \sum_{c \in \mathcal{C}} w(c)$.
    \end{itemize}

\end{mydefinition}
