\section{Certified Algorithm}

\noindent In this section we present an Algorithm that finds $\gamma$-certified solutions to the FVS-4CL problem.
The algorithm is similar to Algorithm~\cite[4.2.1]{bumpus_et_al:LIPIcs.SWAT.2024.19}, 
but is adopted to our problem. This distinction will be made clear in the first subsection. 
We will also simulate a run of the certified algorithm, 
in order to find an optimal solution in the second subsection. Finally, in the third 
subsection we give a proof that this algorithm indeed finds $\gamma$-certified solutions.

\subsection{Certified Algorithm for FVS-4CL}

\noindent The algorithm has three main stages. Much like Baker's technique, we first run 
BFS in order to obtain a layer decomposition from an arbitrary vertex $r$. Afterwards, 
we run $A_{\text{FVS-4CL}}$ on a given number of consecutive layers. In this step we claim 
that we will find a better solution if there is one within those layers, otherwise we 
choose the next block of layers. Once we loop through the graph in the second step, 
we get an optimal solution. In the third step we perturb the weight function in a way 
that would give us a certified solution. 

\noindent Before we give the algorithm we will define some concepts, that we will make use of.

\refstepcounter{definition}
\begin{mydefinition}[$\kappa$-layered subgraph]{Def.}
    \label{def:k-layered-graph}

    Let $G$ be a planar graph and $\kappa$ a natural number. Let $J$ be the set of vertices of 
    any $\kappa$ subsequent layers, where the layers are a result of a BFS run. Then the 
    graph $G[V(J_{\kappa})]$ is a $\kappa$-layered subgraph. We denote such a subgraph $G_{\kappa}$. 
    If the set of vertices $J$ is made of $\kappa$ subsequent layers, then we denote it as 
    $J_{\kappa}$.

\end{mydefinition}

\noindent For more clarity on Def~\ref{def:k-layered-graph}, one can consult line~\ref{line:4} of 
Algorithm~\ref{alg:baker} and Fig.~\ref{fig:bfs_tree} where for the first time we defined a subgraph $G_{i, j}$ 
and subsequently sketched it.
Our graph $G[V(J_{\kappa})]$ is really a subgraph $G_{i, j}$ of $G$ with width $\kappa$ (of $\kappa$ layers).

\noindent Notice that Algorithm~\ref{alg:stitch-fvs-4cl} takes as input a graph and a weighted 
function $(G, w)$, a feasible solution $S$ and some vertex set $J$. 

\begin{algorithm}[H]
    \caption{Certified Algorithm}
    \label{alg:certified-algorithm}
    \begin{algorithmic}[1]
    \REQUIRE Planar graph $G = (V, E)$, weight function $w : V(G) \to \mathbb{N}$, parameter $\epsilon$
    \ENSURE Solution $S$ to FVS-4CL in $G$, $(1 + \epsilon)$-perturbed weights $w'$ of $w$ that certify $S$.
    \STATE Perform \textsc{BFS} from some arbitrary vertex $r$ \label{line:bfs-one}.
    \STATE $L_i = \{v \in V(G)$ $|$ $d(v, r) = i\}$ for $i = 0, \dots d_{\text{max}}$ \label{line:bfs-two}.
    \STATE Compute a feasible solution $S$ to $G$ according to Def.~\ref{guessable}.
    \STATE Let $k \leftarrow \lceil \frac{2m}{\epsilon} \rceil + 2m$.
    \WHILE {there exists a subgraph $G_{\kappa}$ of width $k-2m$ such that \[w(A_{\text{FVS-4CL}}((G, w), S, J_{\kappa})) < w(S)\]} \label{line:while}
        \STATE $S \leftarrow A_{\text{FVS-4CL}}((G,w), S, J_{\kappa}$)
    \ENDWHILE
    \STATE $w' : V(G) \to \mathbb{N}$, \[
    w' : v \to 
    \begin{cases} 
        w(v), & \text{if } v \in S \\
        (1+\epsilon)w(v), & \text{otherwise}.
    \end{cases}
    \]
    \RETURN $(S, w')$.
    \end{algorithmic}
\end{algorithm}

\noindent The first stage consists of performing BFS from an arbitrary vertex $r$. This is done on 
lines~\ref{line:bfs-one},\ref{line:bfs-two} and is vital when later we have to choose a vertex set 
$J_{\kappa}$.

\noindent In the second stage, we compute a feasible solution, set $k$ and loop through 
the layers looking for a better solution. 

\noindent A word on the argument $k$ and the value that we set it to. In our case, for the FVS-4CL problem, 
$m$ is equal to two. Therefore, $k = \lceil \frac{2m}{\epsilon} \rceil + 2m \geq 5$. Notice that the set 
$J_{\kappa}$ is of width $k-2m$, therefore the $m$-neighbourhood (2-neighbourhood) is of width 
$k - 2m + 2m = k$. Therefore, the graphs within we stitch are of width $\geq 5$.

\noindent As we will argue later more formally, the while statement 
is the one that dominates running time and provides us with an ultimately optimal solution $S$ on $(G, w)$.
Note that in the worst case there will be $W \cdot n$ calls to line~\ref{line:while}, where 
$W = \sum_{v \in V(G)} w(v)$. This is because in each iteration we improve the value of the solution 
by at least 1, notice that we have used natural numbers for the weight functions. 

\noindent In the final stage, we obtain a weight function for which we claim that Algorithm~\ref{alg:certified-algorithm} 
is $(1 + \epsilon)$-certified.
